# Archived promotion campaigns

Mỗi thư mục con là một snapshot độc lập của chương trình đã kết thúc. Snapshot có HTML tự chứa CSS, media cục bộ và hướng dẫn tái kích hoạt.

- `stroke-screening/`
- `cervical-screening/`
- `breast-screening/`
- `thyroid-screening/`

Media tái sử dụng nằm trong từng snapshot hoặc `promotion/assets/`; đường dẫn media cũ tại thư mục gốc không còn được duy trì. Không liên kết trực tiếp các snapshot archived từ trang chủ.
